**统计研究创新性定位判据**

以下是用户确认的评判标准。用于定位统计贡献的类型、层级与潜力，并在层级内按十分制评分，保留一位小数。这是用户自定的有序评价尺度，不作为学界统一评分，也不替代正确性检查或预测长期影响力；分数差不表示等距的贡献差，分数比也不表示贡献倍数。

**1．评判对象：问题、解法和成果必须分开**

- 研究问题的新颖性：是否提出了重要而未被妥善回答的问题。
- 解决方案的创新性：是否提供了现有结果无法直接给出的概念、方法、理论或分析框架。
- 实际完成的贡献：上述创新是否已被定义、证明、实现或验证。

一个问题重要、困难或者长期未解，都不能单独证明解决它必然需要新的统计思想。一个新问题也可能通过成熟方法得到满意答案；一个经典问题则可能因新的解法产生重要创新。

只看到题目或初步设想时，评估的是条件性的创新潜力。不能把未来可能实现的突破算作已经完成的贡献，也不能因为缺少结果就直接判为低创新。

**2．保留三个主要层级，并增加“无法判断”状态**

| 定位 | 分数区间 | 核心定义 | 支持该定位的主要证据 |
| --- | --- | --- | --- |
| 第一级：基础概念或研究范式创新 | 8.0–10.0 | 改变一类统计问题的提出方式、目标定义、识别逻辑或证据组织方式，并能持续产生新的问题、方法和理论 | 清晰的概念增量；与旧观点的实质差别；能解释已有困惑并产生可发展的新研究问题 |
| 第二级：实质性方法、理论或框架创新 | 4.0–7.9 | 在确定的问题领域中，解决核心障碍，形成可复用的方法、理论结论或分析原则 | 最邻近工作的明确不足；非直接推论的贡献；与贡献类型相称的论证和验证 |
| 第三级：迁移、适配或组合应用 | 1.0–3.9 | 主要贡献是将已有统计方法用于新任务、新数据或新的条件组合，核心困难仍由现有结果解决 | 可以说明到已有问题的归约，主要保证或算法从已有结果直接得到，新增工作主要是适配和验证 |
| 暂无法判断 | 不赋分 | 题意、关键机制、最邻近工作或结果证据不足 | 明确缺失的信息及其可能改变的判断，不强行赋予层级或分数 |

第三级不等于没有价值。它可能具有很高的应用、工程或科学价值，但不符合“必须具有较强统计方法论创新”的选题偏好。

经核对确认“与已有工作实质重复、没有新增贡献”时单列 0.0 分，不归入第三级。仅因材料不足而尚未看出增量，应标为“暂无法判断”，不能记为 0.0 分。0.1–0.9 不使用；不能因为换了应用名称就自动计为第三级创新。

层级不按难度、页数、引用量、作者声望或目标期刊决定，也不直接预测未来影响力。

**3．十分制评分：先定层级，再按锚点细分**

先根据主要贡献的性质定级，再在该层级区间内定位分数。所有给出的分数和区间端点均保留一位小数，例如 6.4、6.0、6.0–6.5。整数锚点定义主要档位，小数表示层级内的细化判断。

| 分数锚点 | 层级 | 对应贡献 |
| --- | --- | --- |
| 10.0 | 第一级 | 奠基性贡献：新的基础观点能够作为一个研究体系的出发点，系统重组核心问题及其方法、理论关系，并导出一系列具体的新问题和结论。 |
| 9.0 | 第一级 | 系统性概念创新：新的基本对象、目标或识别观点，能够统一组织多个相互关联的重要问题，并产生旧观点难以提供的解释和推论。 |
| 8.0 | 第一级 | 明确的基础概念突破：改变一类问题的提出方式、目标定义、识别逻辑或证据解释，并能由此导出具体的新问题或结论。 |
| 7.0 | 第二级 | 领域内的系统性突破：提出具有统摄力的方法原则、理论认识或分析框架，实质改变该领域一类核心问题的解决方式，但仍沿用原有的基础问题观。 |
| 6.0 | 第二级 | 关键原理或机制突破：揭示此前缺少的关键机制、界限或构造原则，使一个重要核心障碍得到深入解决，并提供可复用的认识。 |
| 5.0 | 第二级 | 明确的方法或理论创新：提出新的方法、理论结论或分析思路，解决已有结果无法直接解决的实质障碍，形成清楚的新能力。 |
| 4.0 | 第二级 | 局部但实质的创新：在一个明确、较有限的范围内解决新的核心障碍，贡献超出直接推论或标准适配，形成可复用的局部构造或理论认识。 |
| 3.0 | 第三级 | 系统适配或组合：针对特殊机制完成较深入的适配、重组或方法组合，但关键构造和主要保证仍由已有结果提供。 |
| 2.0 | 第三级 | 针对性适配：根据新条件调整已有方法，例如修改标准构造、检查适用条件或组合现成保证，核心统计思路没有实质变化。 |
| 1.0 | 第三级 | 直接迁移应用：把成熟方法用于新的对象、任务或数据，新增内容主要来自应用场景，统计方法与推断逻辑基本沿用。 |

第二级覆盖从局部实质突破到系统性方法论贡献，因而设置四个整数锚点。方法、理论、建模或框架、统一或综合贡献均可达到相应档位，不以是否提出算法或覆盖多个无关领域决定高低。

**小数的使用。** 在同一层级的相邻整数锚点间，先确认较低锚点成立，再说明超出它的具体内容及尚未满足较高锚点的部分。可用以下参照保持尺度一致，但不将其变成加权公式：

- .0–.3：主要符合该整数锚点，至多有较有限的进一步增量。
- .4–.6：明确超出该整数锚点，已有部分接近下一锚点的贡献，但仍有实质差距。
- .7–.9：接近下一锚点的贡献深度或组织能力，尚缺一项足以支持更高档位的关键内容。

3.0–3.9 与 7.0–7.9 是本层级顶部的细分：前者比较适配中统计内容的深度与组织性，后者比较实质方法或理论认识的深度与统摄力。不能将小数理解为完成更高层级创新的比例，也不能因工程复杂、实验多或成果成熟而抬高小数。10.0 为上限。

**两道硬门槛。**

- 3.9 → 4.0：须指出已有结果不能解决的核心障碍，并提供超出直接推论或标准适配的可复用构造或认识。深入适配仍可能只有 3.9 分；多个旧工具的组合若产生新的解决原则，则可以达到第二级。
- 7.9 → 8.0：须说明基础对象、目标、识别逻辑或证据组织方式发生了什么变化，以及该变化如何产生新的问题与结论。强大的方法或统一框架若未改变基础问题观，仍属于第二级。

分数从所在层级内直接选取，不能先算出连续总分再靠四舍五入跨过门槛。一级内部的高低取决于基础变化的深度及其组织问题的能力，不按声望、引用量或未来能否开辟学科判断。

**评分依据与不确定性。**

- 用最邻近工作的具体差别、所解决的核心障碍、新增的统计认识或能力解释评分，并说明相邻锚点差别。十分位是审慎的细化判断，不代表客观测量精度；解释不支持精细区分时，不强行声称 0.1 分差异有实质意义。
- 证据不足以给单点分数时，可给保留一位小数的区间并说明条件。若区间跨过 4.0 或 8.0，层级也标为待定；完全缺乏定位依据时不赋分。区间是判断范围，不是统计置信区间。
- 多项主要贡献可分别评分；总体定位由支撑主要结论的核心贡献决定，不求平均、不累加，也不由边缘亮点决定。
- 题目或设想给条件性潜力分，说明对应路线与成立条件；已有成果给当前贡献分。主张的创新尚未验证时，报告条件性定位与验证状态，不能将未成立的主张计为已完成贡献。
- 成熟度、正确性或验证状态、新颖性判断置信度分别报告。应用重要性、自然性、可行性及工程投入不作为创新分数的补偿项；证明尚未核验也不直接折算成低创新分。

评分输出示意：“第二级，6.4/10，理论创新；当前贡献评价。超出 6.0 锚点的依据是……，尚不支持 7.0 的原因是……。验证状态：……；判断置信度：中，原因是……。”题目阶段须将“当前贡献评价”改为“条件性潜力评价”，并写明成立条件。

**4．第一级的判断：基础性变化，而非笼统的大方向**

第一级通常需要有证据回答：

1. 新观点改变了什么基本对象、关系、识别问题或证据解释？
2. 旧观点为什么容易遗漏问题、混淆对象，或持续限制有效研究？
3. 新观点能否组织一类具有共同结构的问题，而不只是解释一个案例？
4. 它是否已经导出了新的、可检验或可推演的问题与结论？

因果推断可作为这一贡献类型的参照：关注的不只是标签缺失，还包括干预目标、反事实关系与识别条件的组织方式。该参照不意味着只要出现缺失数据或不可识别性，就达到了同一层级。

在早期选题中，通常只能判断“具有第一级潜力”或“尚无支持第一级的证据”。“会开辟一个学科”是长期历史判断，不是可以在选题阶段承诺的结果。

不要求新概念无法用既有概率或优化语言表达。能够被既有数学表达，不等于概念增量不存在。

**5．第二级包含并列类型，不设置算法高于理论的顺序**

| 类型 | 可能成立的贡献 | 单独不足以成立的表述 |
| --- | --- | --- |
| 方法或算法创新 | 新的程序、设计原则或推断构造解决关键障碍，在有效性、效率、鲁棒性或计算可行性上带来实质进展 | “设计了一个算法”“比某个弱基线表现好” |
| 理论创新 | 新的识别界限、最优性结论、检测边界、效率界、适应性代价或不可能性结果，改变对问题的理解 | “证明了一条定理”“在一个新参数范围重写了旧证明” |
| 建模或框架创新 | 提炼出核心机制，连接目标、假设、方法与保证，能分析、比较或设计一类方法 | “把问题写成假设检验”“定义了一组符号和流程” |
| 统一或综合创新 | 已有观点的统一带来此前缺少的解释、比较准则、方法推导或实质性结果 | “把多个方法放进一张图”“把三种已有工具串起来” |

Lasso 可以作为方法型贡献的参照，大语言模型水印中连接枢轴统计量、检测效率与检测规则的统计框架，可以作为框架型贡献的参照。这里只比较贡献类型，不预言任何新工作会获得相同的历史影响。

不要求每项工作同时提出新算法、证明下界并匹配上界。证据要求应随贡献类型变化：纯理论成果可以达到第二级；缺少最优性定理也不自动否定一个有充分依据的重要方法。

**6．第二级与第三级的核心分界：已有结果是否已经解决主要困难**

首先明确最接近的已有方法或定理，再判断：

- 能否在保持目标、数据获取方式和主要约束的前提下，把问题归约到已有框架？
- 归约后的假设在现实机制下是否成立，是否需要付出额外数据、计算或验证成本？
- 现有保证是否回答真正关心的问题，精度和成本是否足以支持实际决策？
- 如果不能直接解决，具体失败在哪一步？新的工作如何修复它？

判别原则：

- 若只需更换损失函数、代入参数、做标准条件检查或组合已有保证，且没有解决新的核心障碍，通常偏第三级。
- 若现有方法在关键处失效、代价不可接受，或根本不能回答目标问题，而新贡献提供了可复用的解决原则，则可能达到第二级。
- 若多个成熟因素的组合产生了新的相互作用，组合本身也可以具有创新；应展示这种相互作用，而不是把复杂因素的数量当证据。
- 即使新结果可被写成某个一般理论的特例，也不能据此自动降级。一般理论若不能提供有用的构造、可验证的条件或可行的计算方法，重要的方法创新仍可能存在。

“非平凡”不等于证明长或技术复杂。短而关键的新论证可能很重要，复杂的技术适配也可能仍然属于第三级。

**7．评估采用七个观察维度，但不机械加权打分**

| 维度 | 需要回答的问题 |
| --- | --- |
| 概念增量 | 是否新增了有解释力的对象、区分、机制或研究视角？ |
| 核心障碍 | 最接近的已有工作在哪个关键环节不能解决问题？ |
| 解决原则 | 新工作提供了什么可复用的构造、设计思想或推理原则？ |
| 理论增量 | 哪些关于识别、有效性、效率或极限的结论发生了实质变化？ |
| 适用范围 | 新认识能覆盖哪些机制、分布、任务或方法，而不只服务于一个实验？ |
| 证据充分性 | 论证和实验是否真正支持声称的贡献，并公平比较最接近基线？ |
| 统计表述的自然性 | 目标参数、假设和约束是否来自实际问题，而非为了套用某种技术而人为添加？ |

这些维度不是必须全部高分的清单。理论型成果可以不提出算法，应用领域很专门的成果也可以高度创新。适用范围应相对于该领域的重要问题类判断，不要求跨越很多无关领域。

这些观察维度用于支持层级和评分锚点的判断，不分配固定权重再相加。概念、方法和理论贡献按其类型比较；证据充分性用于限定判断与验证状态，自然性单独报告，不能通过加权总分“补足”概念与方法增量。

**8．常见边界情况**

- 新场景不自动等于新统计问题；“首次用于某领域”本身不足以支持第二级。
- 稀有事件、小样本、序贯性、自适应、对抗性、非独立性、缺失标签等都是困难线索，不是创新结论。
- 放宽假设应核对是否同时引入了另一项强假设。假设不可比较时，要报告权衡，不能笼统称为“更弱”。
- 参数范围扩大、速率改进或常数改善，应解释它是否揭示了新机制或解决了实质障碍。不能只按公式中有无新的阶数决定层级。
- 使用成熟工具不自动降级；关键在于这些工具是否产生了新的分析原则或解决了此前的关键障碍。
- 不能用“新框架”的命名替代内容。框架应帮助理解、比较或设计一类方法，并带来具体结论。
- 显然的无假设不可能性，与揭示精确识别边界、关键条件或资源代价的不可能性结果，创新程度不同。
- 软件实现、规模扩展、数据集和基准可能很有价值，但应分清工程或资源贡献与统计贡献。
- 计算创新若改变了重要统计方法的可实现性，并保留或改善其统计性质，可以属于第二级，而不应一律降为工程。
- “去掉应用名称”的检查应保留真正的数据生成、干预、采样和决策机制。不能删掉水印、自回归或其他关键机制后，再批评问题没有特色。
- 不能把一个方向中未来可能出现的贡献，记在当前尚未实现的方案上。
- 不能为了升档，悄悄把原问题换成更大的问题。若确实更换目标或引入新的核心机制，应明确说明是选题重构。

**9．创新性、重要性、自然性和可行性分别报告**

创新性回答“增加了什么统计认识或能力”。

重要性回答“谁需要这个答案，答案是否改变科学或实际决策”。

自然性回答“为什么这是该实际问题真正需要的统计对象与约束”。

可行性回答“数据、验证条件、理论起点、计算与时间是否支持推进”。

四项可以相互影响，但不能互相替代。低创新、高重要性的项目可以值得做；高创新潜力、低可验证性的项目也可能不适合作为当前主线。是否推荐立项，应在用户要求时另行判断。

**10．题目阶段与成果阶段使用不同输出**

对于题目或初步设想：

- 给出最自然技术路线可能达到的层级与条件性潜力分，并说明条件。
- 给出有证据支持的更高层级或更高分数潜力，明确它对应的技术路线或实质发现，不把多个情景混成当前分数。
- 指出升级所需的关键发现，以及尚未证明的部分。
- 说明现有方法直接覆盖该问题的风险。
- 不把缺少论文或实验当作“确定属于第三级”的证据。

对于已有方法、定理或论文：

- 分别判断各项主要贡献的层级与分数，保留一位小数，并解释相邻锚点差别。
- 对照最接近结果，区分直接推论、非平凡扩展和新的原则。
- 检查比较是否使用相同目标、信息、成本和假设。
- 将正确性、验证充分性与创新层级分开报告；新想法但证明不充分，不等于创新低，也不等于成果已成立。
- 总体层级与分数由支撑主要结论的核心贡献决定，不由边缘的小贡献或最强宣传语决定，不平均或累加各项分数。

**11．文献证据和判断置信度**

评估优先使用最邻近的原始论文、定理和方法，而不是只比较同一应用标签下的文献。需要检查统计学、机器学习、运筹学、控制等邻近领域的等价问题。

“尚未找到”不能写成“没有人做过”。同一文献的摘要承诺、正式定理和实验证据也需要区分。

- 快速定位：依据已有材料给条件判断，说明未核实的最邻近工作和关键假设。
- 核验定位：补充针对性的文献与方法检查，再给出较强结论。
- 用户要求不检索时，遵从要求，并明确判断范围。

判断置信度可用高、中、低表达，但必须附理由。完成大量搜索并不自动意味着高置信度；准确定位最邻近结果、明确可归约部分和核心增量更重要。

已有成果的验证程度，与新颖性判断的置信度不同，应分别说明。
