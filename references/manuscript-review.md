**四维稿件审核与新增三项十分制标准**

用于完整审核统计学及相关机器学习研究稿件。一级维度只有创新性、重要性、可靠性、表达质量；假设合理性、实验设计、可复核性等是内部检查点，不另列评分维度。

创新性严格使用 [现有创新判据](rubric.md)，保留原三级定义、分数区间、整数锚点、小数规则及例外状态。本文件仅定义另外三个维度，并规定完整审核的组织方式。这是自定的工作标准，不是期刊或会议的官方评分表。

**1．评分对象与共同规则**

- 新增三个维度各用 1.0–10.0 分，分数及区间端点保留一位小数；不沿用创新性的三级分类、4.0/8.0 升级门槛或 0.0 特殊状态。信息不足不记为最低分。
- 四项独立判断，不相加、不求平均、不生成默认加权总分。同一数值在不同维度具有不同含义；可靠性 6.0 不等于创新性 6.0，也不是统一的投稿通过线。
- 先说明评价的是问题或设想、当前稿件还是修订后的条件性情景。重要性可评价问题的潜在价值，但要区分当前成果已实现的贡献价值；可靠性只评价现有论证与证据，表达质量只评价实际提供的文本。
- 材料不足以定位时写“暂无法判断”；关键材料已提供但尚未检查时写“未核验”。只有摘要时，可以评价摘要表达，不能据此给整篇稿件的可靠性或表达质量定分。没有稿件时不预测未来稿件的表达分。
- 与稿件类型无关的检查项标为“不适用”，不扣分。纯理论稿件不因缺少实验、代码或应用而自动降低可靠性；方法或应用稿件也不被强制要求提出新理论或匹配上下界。
- 分数必须对应材料中的具体内容，指出为何超过较低锚点、尚缺什么才达到更高锚点。十分位不代表测量精度，无法合理细分时给区间或整数锚点的一位小数形式。

在相邻整数锚点之间，可用以下参照：.0–.3 主要符合较低锚点，至多有有限的进一步内容；.4–.6 明确超过较低锚点，但与较高锚点仍有实质差距；.7–.9 已接近较高锚点，仍有可指出的不足。10.0 为上限。先满足有关核验要求与缺陷限制，再细分小数，不能靠四舍五入越过限制。

**2．三个维度分别评价什么**

**重要性：这项工作有多大价值。** 判断问题及其答案对统计认识、研究方法、科学理解或实践决策的意义。说明受益对象、现有需求及结果成立后具体改变什么。重要问题不自动使其任何局部改进都具有同等价值；完整稿件主要评价它实际贡献的价值，必要时另述问题本身的潜在价值。

理论价值与实际应用价值均可独立成立。围绕相关问题领域衡量价值，不以热门程度、引用数、作者声望、目标期刊或覆盖无关领域的数量计分。重要性不等于创新幅度：成熟工具也可能解决重要问题，新概念也可能只带来有限价值。作者没有讲清意义时，先核实能否从结果本身判断；不要仅因动机写得差就断定工作不重要。

**可靠性：现有结论是否得到可信支持。** 围绕支撑主要结论的材料，检查问题设定和假设是否恰当、方法与证明是否成立、实验比较是否公平，以及结论是否超出证据。必要时检查算法与定理是否对应、是否依赖不可获得的信息、计算成本是否符合声称的使用场景，以及复核关键结果所需的细节是否充分。

统计推断稿件应核对功效或区间长度的改进是否以错误率、覆盖率失守为代价；实验稿件应核对数据划分、信息泄漏、调参和预算公平性、随机误差及关键对照。稳健性检查围绕论文实际声称展开，不无条件要求所有分布、任务、实验或附加证明。

**表达质量：能否清楚、准确且便于核查地传达工作。** 检查动机、问题、贡献、方法、结果与限制是否形成清楚主线，文献关系是否准确，定义、符号、图表与必要细节是否一致且易于定位。表达质量不以英语华丽程度、篇幅或格式精美程度计分；简短、准确的理论稿件也可获得高分。

**3．整数评分锚点**

| 分数 | 重要性 | 可靠性 | 表达质量 |
| --- | --- | --- | --- |
| 10.0 | 对重大核心问题具有决定性价值，能够满足相关领域长期发展的关键需求；有具体依据支持这种价值判断。 | 在明确声称和已核查的范围内，核心论证与证据近乎无可识别缺口，关键检查可复核，未发现实质不足。 | 表达具有示范性：复杂思想被准确、简洁地组织，贡献、依据与边界清楚，读者可以高效理解并核查。 |
| 9.0 | 对核心认识、研究能力或重要实践具有深远价值，其意义可延伸到多个密切相关的关键问题。 | 核心结论的支持非常充分，重要边界和敏感环节得到有针对性的核查，论证与证据可追溯，仅有很小不足。 | 主线、技术细节和直觉解释高度协调，文献定位及限制准确，几乎没有妨碍理解或核查的问题。 |
| 8.0 | 解决一类重要问题中的关键瓶颈，能够显著推进相关研究或实践。 | 核心论证严谨，适用条件和限制交代清楚，关键验证充分，复核信息齐备；剩余不足不影响主要结论。 | 内容准确、结构紧凑、贡献突出，复杂部分有有效解释，只有局部表达可以改善。 |
| 7.0 | 对领域内核心需求有明确而较大的价值，能改善一类重要问题的理解或处理方式。 | 主要结论有充分支持，假设与方法匹配，关键证据和比较合理；存在少量不影响核心结论的不足。 | 研究动机、贡献与论证脉络清楚，定义和图表大体准确，读者能较顺畅地理解和查找依据。 |
| 6.0 | 回答一个重要问题，对相关认识、方法选择或实际决策产生明确收益。 | 核心论证基本闭合，关键材料已核查，主要结论得到合理支持；仍有应补充但不动摇主要结论的内容。 | 主要内容可以完整理解，结构基本合理，必要信息大体可找到，但组织、术语或解释仍需较明显改善。 |
| 5.0 | 解决有明确意义的领域问题，具有可说明的理论或实际收益，但贡献价值较集中。 | 有实质支持，但当前主要声称仍有重要证据缺口或需要收窄；尚需实质补充，未确认核心结论被推翻。 | 整体意思能够理解，但贡献、方法与结果之间的连接较弱，读者需要反复推断或查找关键内容。 |
| 4.0 | 满足一个具体需求，贡献价值明确但有限，对更核心问题的作用尚弱。 | 稿件本身的关键推导、条件或必要验证缺失，主要论证尚未闭合；已有局部结果可核查。 | 核心问题大致可辨，但结构混乱、定义不统一或重要解释缺失，显著妨碍理解。 |
| 3.0 | 对较局部的问题有一定用处，但对相关认识或实践的改变较小。 | 已确认存在实质影响核心结论的错误或无效验证；部分局部结果仍可保留，当前主要声称不可靠。 | 可以辨认部分研究意图，但关键概念和结论多处含混，难以建立一致的理解。 |
| 2.0 | 主要满足边缘或很小的需求，现有认识或方法已基本满足相关需要。 | 核心问题设定、推理或证据存在根本性失配，当前主要结论缺乏有效支撑，需要重建主要论证。 | 只能理解零散部分，目标、方法和结果相互脱节，关键对象难以辨识。 |
| 1.0 | 经具体分析，工作对所声称问题几乎没有可识别的理论、科学或实践价值。 | 核心主张已被决定性反例或根本错误否定，现有材料不能支持当前主要结论。 | 无法从现有稿件识别一致的研究问题、主要贡献或核心结论，表达基本不可用。 |

高重要性不要求预测长期历史影响；高可靠性不表示完成形式化证明认证或穷尽所有错误；高表达质量不表示结论正确。各档比较内容本身，不把其他维度的优势作为加分项。

**4．可靠性分数必须与缺陷和核验状态一致**

可靠性是对现有工作的判断，审核者的判断置信度是另一项信息，不混为一谈。可靠性分必须附核验范围及关键缺陷状态，必要时为各项主要声称分别说明。

- **存在推翻核心结论的实质问题**：已有可定位的反例、推导错误或使主要证据失效的问题，可靠性限于 1.0–3.9。指出具体依据及受影响的结论；不能把可纠正的排版或符号错误一律按此处理。
- **存在重要论证或证据缺口**：检查发现稿件本身缺少支撑主要声称的关键条件、推导或验证，可靠性限于 4.0–5.9。没有发现反例不等于结论已经成立。
- **已检查范围内未发现核心问题**：核心论证与关键证据已实际检查，主要结论有合理支持，才考虑 6.0 及以上。8.0 及以上应有充分的针对性核查记录，不能只凭摘要、作者保证或期刊声望赋分。
- **尚未充分核验**：核心材料未提供或尚未检查到足以定位的程度，不强行给整篇可靠性分；写明缺失或未核验范围，以及改变判断所需的检查。稿件声明存在的附录未被提供给审核者，不等于稿件没有证明。

区间若跨越上述状态边界，必须写明状态待定以及各端成立的条件；已有明确反例时，不用跨界区间回避已确认问题。即使稿件还有许多正确的小结果，也不能通过平均分掩盖核心结论错误。

发现问题后，优先区分应纠正错误、补充证据，还是收窄主张。作者实际修复或明确收窄结论后，可以按新稿重评；不能提前把预期修复计入当前分数。错误主张不能计为已完成的创新贡献；若仍有独立的新思路，按原创新判据单独说明其内容与成立条件。

可复核性要求随研究类型和数据条件变化。纯理论稿件的可复核性体现在定义、条件与证明；数据存在合理访问限制时，可以依据充分的处理说明、受控访问或其他核查途径判断，不因无法公开原始数据就自动扣分。

**5．完整审核的输出**

默认先给四项独立评价，不扩展一级维度，也不只报数字。建议使用下表，按材料精简：

| 维度 | 分数或状态 | 主要依据与最关键不足 |
| --- | --- | --- |
| 创新性 | 原三级定位＋一位小数分数，或暂无法判断 | 最邻近结果、核心增量、相邻创新锚点差别；注明当前贡献或条件性潜力。 |
| 重要性 | 一位小数分数或判断区间，或暂无法判断 | 对谁、对什么问题有价值；区分问题价值和当前贡献价值。 |
| 可靠性 | 一位小数分数或判断区间，或未核验 | 已检查的核心材料、缺陷状态、影响范围及必要修复。 |
| 表达质量 | 一位小数分数或判断区间，或暂无法判断 | 实际阅读范围；最影响理解或核查的表达问题。 |

另行简要报告判断置信度及其理由。最后指出最优先解决的问题，每条意见尽量包含“稿件位置—问题依据—对结论的影响—建议修复”。按影响核心结论的问题、主要补充、表达修正排序，不为凑数量提出额外实验或扩大研究范围。

用户指定目标期刊或会议时，可结合四项评价说明匹配度与投稿准备情况，作为总体建议而非第五项评分。没有指定目标时不强行给出录用预测。各项分数都不直接换算成录用概率；核心错误或重要证据缺口不能被创新性、重要性或表达质量的高分抵消。

**6．校准情形**

以下是条件性示例，用于检验维度之间是否混淆；示意分不是对研究方向的固定赋分。

| 情形 | 应如何评价 |
| --- | --- |
| 用成熟统计工具解决一个重要的实际决策需求，收益得到清楚说明 | 创新性仍按原判据，可能属于第三级；重要性可达到 7.0 或更高，不互相补分。 |
| 提出新构造，但它只改善边缘情形且收益很小 | 创新性独立判断，重要性可以较低；不能仅凭“新”抬高重要性。 |
| 一个小众理论问题揭示了该问题领域的重要结构，无直接应用案例 | 按其理论价值判断重要性；不因领域专门或缺少应用而自动低分。 |
| 稿件提出有价值的关键机制，但主要性能声称仅由局部证据支持，遗漏会影响结论的必要比较 | 可靠性可示意为 5.4/10，标为重要证据缺口；不直接断言方法错误，也不把声称的优势当作已充分验证。 |
| 主定理存在明确反例，其他实验很多，文字也很清楚 | 可靠性限于 1.0–3.9，核心错误单独报告；实验数量和表达高分不能抵消。 |
| 完整纯理论稿件的定义、核心证明与关键边界已认真核查，论证严密，没有算法或实验 | 可靠性可达到 8.0 或更高；算法、实验和代码等不适用项不扣分。 |
| 用户只提供摘要，并说明证明在尚未提供的附录里 | 不给整篇可靠性分；可以限定评价摘要的表达，并说明创新性和重要性判断的不确定性。 |
| 方法很重要，但论文动机写得差；结果的实际价值能从材料中独立确认 | 重要性按实际价值评价，表达质量单独降低；不因写得差否定已确认的价值。 |
| 语言流畅、图表精美，但关键定义互相矛盾，贡献表述夸大 | 表达质量不能仅凭流畅度高分；可靠性另按是否已查明实质问题判断。 |
| 修订只改善结构与措辞，贡献、结论和证据均未变化 | 主要调整表达分，其他分数不机械随之提高。若澄清使实际贡献或证据被重新理解，应说明重评原因。 |
