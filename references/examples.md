**创新层级的边界校准示例**

仅在需要解释边界、检查定位一致性或用户要求例子时读取。各行都是条件性示例，不是对某个研究方向预先赋予层级。下表的迁移、适配案例以没有独立的实质性新认识贡献为前提；若实际材料包含新发现，须另按完整判据核查，不能只因工具相同而照搬低层级。

| 情形 | 初步定位 | 关键理由 |
| --- | --- | --- |
| 用现成二项置信区间估计某个新模型的违规率 | 第三级 | 应用对象变化，核心统计推断未变化 |
| 把逆概率加权与既有置信序列用于选择性人工复核，相关假设可直接满足 | 通常第三级 | 核心保证已有，主要工作是组合与适配 |
| 证明一个此前未知且实质性的认证成本边界，并给出达到该边界的可行方法 | 可支持第二级 | 产生新的理论认识和方法设计依据 |
| 为一类机制建立共同的统计对象，使不同方法能被比较并推导新的有效规则 | 可支持第二级 | 统一产生了新的分析和设计能力 |
| 提出新的证据或识别观点，持续导出一类重要问题和解决原则 | 第一级候选 | 存在范式潜力，但长期影响仍不能预先保证 |
| 没有提出算法，但证明了此前未知且改变问题理解的尖锐识别界限 | 可支持第二级，理论型 | 是否提出算法不决定理论贡献的层级 |
| 结果可写成一般理论的特例，但首次给出实质解决计算或验证障碍的可复用构造 | 可支持第二级，方法或框架型 | 能够归约不等于关键困难已经被现有结果解决 |
| 题目很重要，但还未定义观测信息，也未核查相邻文献 | 暂无法判断 | 信息不足，不能等同于创新性低 |

以上定位都以例子中所述条件成立为前提。“证明了新界限”或“提出统一框架”只是贡献描述；正式评价仍需确认它确实新、正确且具有实质内容。

**一位小数评分的校准示例**

下表演示评分表达与层级边界，不是对某个研究方向的固定赋分。示意小数需在实际评估中用最邻近结果和具体增量重新校准，不能只凭贡献名称照搬。

| 已知条件 | 评分表达示意 | 关键理由 |
| --- | --- | --- |
| 深入组织多个现成统计工具并处理机制适配，但核心构造与保证均可从已有结果直接得到 | 第三级，3.6/10 | 本层级内的统计适配内容较强，仍未跨过实质创新门槛；工程投入或完成度不作为加分理由 |
| 揭示重要核心障碍背后的新机制，并有超出 6.0 锚点的具体可复用推论，但尚未形成 7.0 所需的统摄力 | 第二级，6.4/10 | 用超出较低锚点与尚未达到较高锚点的具体内容解释小数 |
| 一个很强的统一方法体系改变了相关问题的解决路线，但目标、基本对象和识别观点仍沿用既有定义 | 第二级，7.8/10 | 高方法论贡献不自动变为基础概念或范式创新 |
| 新的证据观点改变一类问题的组织方式，导出具体的新问题与结论，但尚未形成系统重组多个相关问题的能力 | 第一级，8.2/10；按材料注明当前贡献或条件性潜力 | 先确认 8.0 门槛，再按基础变化的深度与组织能力细分；不预言历史影响 |
| 一个提出新关键机制的设想，若成立可支持 6.0 锚点，但核心论证尚未完成 | 第二级条件性潜力，6.0/10；已完成贡献尚未确认 | 缺少证明限制验证状态，不能直接判为第三级，也不能算作已完成的 6.0 分贡献 |
| 已有依据将贡献限定在深入适配与局部实质突破之间，但最邻近一般定理是否覆盖关键构造尚未核实 | 层级待定（第三级或第二级），3.6–4.2/10；说明两端条件 | 跨层级区间必须同时标明层级不确定，核实后再定级；不是统计置信区间 |
| 经核对，目标、机制、构造与结论均与已有工作实质重复，没有新增贡献 | 0.0/10，重复或无新增贡献，不归入第三级 | 已确认没有增量与材料不足是不同状态 |
| 只有题目，观测机制和核心方法均不清楚，无法限定可能贡献 | 暂无法判断，不赋分 | 不用 0.0 分或其他低分代替信息不足 |

同一份成果若只增加实验数量、完善证明文字或提高判断置信度，而所声称的统计增量没有变化，不因此机械提高创新分。若新增证据揭示了不同于原先判断的贡献内容，或证明最邻近工作已覆盖该贡献，则应据此重新定位。

**使用已有工具获得新认识的对照示例**

以下仍属于同一个创新性维度，沿用原有层级、整数锚点和小数规则。示意锚点不代表已执行真实稿件的独立重复评分；材料是否满足各项条件需要实际核查。

| 已知条件 | 应如何定位 | 与常规应用或更高锚点的分界 |
| --- | --- | --- |
| 用已有工具首次揭示一个有限但明确范围内的未知限制，相关文献没有同一认识或标准解释，反例或数据证据支持该限制 | 可支持第二级的 4.0 锚点 | 实质增量是限制本身，不是更换数据集；若只是已知限制的新案例，仍按原适配尺度评价。 |
| 用现成方法形成可复用的新发现，区分此前混淆的两种解释，但尚未解决关键认识障碍 | 可支持第二级的 5.0 锚点 | 具有清楚的新判断依据；不能仅因应用价值高就提高到 6.0。 |
| 用初等概率和现成模拟揭示一类推断程序此前未识别的关键失效机制，说明条件并有可复用推论，但尚未形成系统性认识 | 可支持第二级的 6.0 锚点 | 核心贡献是关键机制；没有新算法或复杂证明不构成降级理由。 |
| 通过一个经过核查的反例否定核心全称解释，实质改变问题理解，尚未给出替代解释或修复算法 | 按认识增量判断，可支持 6.0；不自动归入第三级 | 单个反例可完成其否定主张；是否达到 6.0 取决于被排除解释的核心地位和新增认识，不能把任意反例都视为关键突破。 |
| 用现有工具建立有相称证据支持的稳定经验规律，改变对核心现象的理解，但完整机制尚不清楚 | 按实际认识增量定位，可达到第二级 | 不强求完整机制理论；有限实验只支持有限范围，不能提前把普遍性计为当前贡献。 |
| 多项相互联系的新认识形成统摄性解释或判断原则，实质改变一类核心问题的理解与处理方式，基本对象和目标未改变 | 可支持第二级的 7.0 锚点 | 按组织认识的能力定位，不以结果数量加分，也不自动进入第一级。 |
| 新发现进一步改变基础目标、识别逻辑或证据组织方式，并导出具体的新问题与结论 | 按原门槛判断第一级候选 | 工具已有不封顶于 7.9；仍须满足 8.0 及以上各原有锚点。 |
| 在新数据上观察到已有文献已经解释的失效现象，新增工作是验证和适配，没有新的条件、关系或认识 | 沿用第三级尺度，按实际适配深度评分 | 结果重要或令人惊讶不自动升级；重要性另行评价。 |
| 用成熟统计工具发现有价值的应用领域事实，但没有增加统计或学习认识 | 明确应用领域的科学贡献，统计创新沿用原判据 | 不把“统计方法沿用”说成“科学上没有价值”，也不把应用重要性直接换算为统计创新分。 |
| 只有异常曲线或显著性结果，关键实现、随机误差或替代解释尚未核查，无法确定所声称的新现象 | 暂无法判断；有明确条件时可另述潜力 | 不把未知强行记为第三级，也不把未核实观察计为已完成的新认识。 |
| 新定理或新方法已按原尺度得到合理定位，没有额外的独立认识贡献 | 原评分锚点和层级依据保持不变 | 不因新增 insight 判据而加分、减分或重复计新。 |

**经典文献中的贡献形态参照**

以下引用具体贡献作为判据说明，不给历史论文固定分数，不把经典声望或后来影响作为创新依据，也不声称完成了全面的历史优先权核查。部分论文另含理论结果；本表只解释与新认识有关的部分。

| 原始文献 | 可借鉴的认识贡献及边界 |
| --- | --- |
| [Simpson（1951），The Interpretation of Interaction in Contingency Tables，JRSS-B](https://math.bme.hu/~marib/bsmeur/simpson.pdf) | 用列联表、简单计算与构造例子说明，没有二阶交互作用不足以支持机械合并表格；同样数值在不同背景下可能需要不同解释。原文也承认合并表格的风险已有讨论，不能把所有相关现象都记为首次发现。 |
| [Bertrand、Duflo、Mullainathan（2004），How Much Should We Trust Differences-in-Differences Estimates?，QJE](https://sendhil.org/wp-content/uploads/2019/08/Publication-53.pdf) | 以既有回归和虚拟政策实验揭示忽略序列相关时的严重推断失准。序列相关理论已有，实质增量包括识别它在常用研究设计中的严重后果及其量化证据；不能泛称首次发现序列相关。 |
| [Zhang 等（2017），Understanding Deep Learning Requires Rethinking Generalization，ICLR](https://arxiv.org/pdf/1611.03530) | 使用现有网络与训练方法开展随机标签等实验，挑战仅靠容量或常用显式正则化解释泛化的充分性。论文另有表达能力的理论构造；此处引用其实验性认识，不声称已经解释所有泛化机制。 |
| [Anscombe（1973），Graphs in Statistical Analysis，The American Statistician](https://garstats.wordpress.com/wp-content/uploads/2016/08/anscombe-as-1973.pdf) | 用摘要相近而图形结构不同的数据展示诊断的重要性，作为边界案例：有力展示已知道理与发现未知认识需要分别核查，不能仅凭经典地位自动赋予高创新分。 |
