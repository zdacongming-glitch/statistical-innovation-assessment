**创新层级的边界校准示例**

仅在需要解释边界、检查定位一致性或用户要求例子时读取。各行都是条件性示例，不是对某个研究方向预先赋予层级。

| 情形 | 初步定位 | 关键理由 |
| --- | --- | --- |
| 用现成二项置信区间估计某个新模型的违规率 | 第三级 | 应用对象变化，核心统计推断未变化 |
| 把逆概率加权与既有置信序列用于选择性人工复核，相关假设可直接满足 | 通常第三级 | 核心保证已有，主要工作是组合与适配 |
| 证明一个此前未知且实质性的认证成本边界，并给出达到该边界的可行方法 | 可支持第二级 | 产生新的理论认识和方法设计依据 |
| 为一类机制建立共同的统计对象，使不同方法能被比较并推导新的有效规则 | 可支持第二级 | 统一产生了新的分析和设计能力 |
| 提出新的证据或识别观点，持续导出一类重要问题和解决原则 | 第一级候选 | 存在范式潜力，但长期影响仍不能预先保证 |
| 没有提出算法，但证明了此前未知且改变问题理解的尖锐识别界限 | 可支持第二级，理论型 | 是否提出算法不决定理论贡献的层级 |
| 结果可写成一般理论的特例，但首次给出实质解决计算或验证障碍的可复用构造 | 可支持第二级，方法或框架型 | 能够归约不等于关键困难已经被现有结果解决 |
| 题目很重要，但还未定义观测信息，也未核查相邻文献 | 暂无法判断 | 信息不足，不能等同于创新性低 |

以上定位都以例子中所述条件成立为前提。“证明了新界限”或“提出统一框架”只是贡献描述；正式评价仍需确认它确实新、正确且具有实质内容。

**一位小数评分的校准示例**

下表演示评分表达与层级边界，不是对某个研究方向的固定赋分。示意小数需在实际评估中用最邻近结果和具体增量重新校准，不能只凭贡献名称照搬。

| 已知条件 | 评分表达示意 | 关键理由 |
| --- | --- | --- |
| 深入组织多个现成统计工具并处理机制适配，但核心构造与保证均可从已有结果直接得到 | 第三级，3.6/10 | 本层级内的统计适配内容较强，仍未跨过实质创新门槛；工程投入或完成度不作为加分理由 |
| 揭示重要核心障碍背后的新机制，并有超出 6.0 锚点的具体可复用推论，但尚未形成 7.0 所需的统摄力 | 第二级，6.4/10 | 用超出较低锚点与尚未达到较高锚点的具体内容解释小数 |
| 一个很强的统一方法体系改变了相关问题的解决路线，但目标、基本对象和识别观点仍沿用既有定义 | 第二级，7.8/10 | 高方法论贡献不自动变为基础概念或范式创新 |
| 新的证据观点改变一类问题的组织方式，导出具体的新问题与结论，但尚未形成系统重组多个相关问题的能力 | 第一级，8.2/10；按材料注明当前贡献或条件性潜力 | 先确认 8.0 门槛，再按基础变化的深度与组织能力细分；不预言历史影响 |
| 一个提出新关键机制的设想，若成立可支持 6.0 锚点，但核心论证尚未完成 | 第二级条件性潜力，6.0/10；已完成贡献尚未确认 | 缺少证明限制验证状态，不能直接判为第三级，也不能算作已完成的 6.0 分贡献 |
| 已有依据将贡献限定在深入适配与局部实质突破之间，但最邻近一般定理是否覆盖关键构造尚未核实 | 层级待定（第三级或第二级），3.6–4.2/10；说明两端条件 | 跨层级区间必须同时标明层级不确定，核实后再定级；不是统计置信区间 |
| 经核对，目标、机制、构造与结论均与已有工作实质重复，没有新增贡献 | 0.0/10，重复或无新增贡献，不归入第三级 | 已确认没有增量与材料不足是不同状态 |
| 只有题目，观测机制和核心方法均不清楚，无法限定可能贡献 | 暂无法判断，不赋分 | 不用 0.0 分或其他低分代替信息不足 |

同一份成果若只增加实验数量、完善证明文字或提高判断置信度，而所声称的统计增量没有变化，不因此机械提高创新分。若新增证据揭示了不同于原先判断的贡献内容，或证明最邻近工作已覆盖该贡献，则应据此重新定位。
