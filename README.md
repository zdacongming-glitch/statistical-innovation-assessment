# 统计研究创新性与稿件评估

`statistical-innovation-assessment` 是一个用于统计研究创新定位和稿件审核的 Codex skill。它支持“仅评创新性”和“四维完整审稿”两种基础模式，创新性默认进行五轮真实独立评分，报告均值、样本方差和实际执行次数。仅在明确请求投稿指导时，另行比较刊会契合度或检索适合的出版物。

适用于研究问题、初步选题、方法、定理和完整论文。对于初步设想，评估条件性创新潜力；对于已有成果，评估当前实际贡献。只有摘要或设想时，不强行给整篇稿件的可靠性与表达质量打分。

**0.3.0 更新：在同一创新性量表内补充新认识判据。** 使用已有工具和理论，仍可能发现重要的新现象、关系、机制、边界或解释。评分依据是实际认识增量，不能仅因没有新算法或复杂证明就归入第三级。原有技术、方法与理论创新锚点、另外三个维度及独立重复统计规则保持不变。

**四个评价维度**

| 维度 | 核心问题 | 评分方式 |
| --- | --- | --- |
| 创新性 | 带来了什么新东西？ | 保留三级区间与原技术、理论锚点，在同一十分制内补充新认识判据。 |
| 重要性 | 这项工作有多大价值？ | 独立的 1.0–10.0 分，评价理论、科学或实践意义。 |
| 可靠性 | 现有结论是否得到可信支持？ | 独立的 1.0–10.0 分，同时报告核验范围与关键缺陷。 |
| 表达质量 | 是否清楚、准确且便于核查地传达工作？ | 独立的 1.0–10.0 分，评价实际提供的稿件文本。 |

四项分别报告，不计算维度之间的平均或加权总分；同一对象、同一维度可以汇总跨轮次统计。假设合理性、实验设计、计算可行性、可复核性等属于内部检查点，不另设评分维度。刊会契合度是可选投稿模块的比较结果，不是第五个稿件质量维度。

**创新性评分：保留原锚点，补充新认识判据**

| 层级 | 分数区间 | 核心含义 |
| --- | --- | --- |
| 第一级 | **8.0–10.0** | 基础概念或研究范式创新：改变一类统计问题的提出方式、目标定义、识别逻辑或证据组织方式。 |
| 第二级 | **4.0–7.9** | 实质性方法、理论、框架或认识创新：解决核心障碍，形成可复用的构造、结论、分析原则或实质性新认识。 |
| 第三级 | **1.0–3.9** | 迁移、适配或组合应用：应用对象或条件发生变化，核心统计困难仍由现有结果解决，且没有独立的实质性新认识贡献。 |

先按贡献性质定级，再在该层级内细分，例如 **第二级，6.4/10**。整数分也保留一位小数，例如 **6.0/10**。评分依据包括最邻近工作的不足、具体核心增量，以及相对相邻评分锚点已经达到和仍然缺少的内容。

两道升级门槛：

- **3.9 → 4.0**：技术、方法与理论贡献沿用超出直接推论或标准适配、解决新的核心障碍的门槛；新认识贡献须核实此前未被确立的实质性认识增量，超出已知机制的例证或常规解释。
- **7.9 → 8.0**：必须改变基础概念或问题组织方式，并由此产生具体的新问题或结论。

小数用于层级内细分，不能靠四舍五入跨越门槛，也不代表客观测量精度。证据不足以确定单点分数时，可给出如 **6.0–6.5/10** 的判断区间；跨层级区间须同时标明层级待定。

经核实与已有工作实质重复、没有新增贡献时，单列 **0.0/10**，不归入第三级；材料不足则标为 **暂无法判断**，不赋分。0.1–0.9 不使用。

完整的十个整数锚点、小数细分方法和边界判据见 [完整判据](references/rubric.md)，具体情形见 [边界与评分示例](references/examples.md)。

**使用已有工具获得新 insight 时如何定位**

工具是否已有与认识是否已有分别核查。以下是原评分表补充列的概览，不是新的评分维度，也不与方法或理论贡献相加、平均或机械取最大值。

| 锚点 | 新认识贡献的对应条件 |
| --- | --- |
| 4.0 | 在明确范围内发现此前未被确立的现象、关系、限制或反例，具有实质性认识增量。 |
| 5.0 | 形成明确、可复用的新发现，区分此前混淆的解释，或给出新的判断依据。 |
| 6.0 | 揭示关键机制或失效边界、排除核心惯常解释，或建立改变问题理解的稳定规律。 |
| 7.0 | 新认识形成统摄性解释、判断或研究原则，改变一类核心问题的理解与处理方式。 |
| 8.0–10.0 | 必须进一步满足原有基础概念或范式创新的相应门槛。 |

新发现不强制附带新算法、修复方法或完整机制理论，但证据必须与主张相称：单个有效反例可否定全称主张，普遍经验规律则需要系统证据。重要、意外、显著或首次应用本身不构成升级依据；已知机制的新例证沿用原尺度，材料不足时不强行判低分。新颖性、重要性与核验状态仍分别报告。

**新增三个维度的评分标准**

下表是区间概览；三个维度各自的十个整数锚点与小数规则见 [四维稿件审核标准](references/manuscript-review.md)。这些分数不套用创新性的三级分类，也不共用投稿门槛。

| 分数区间 | 重要性 | 可靠性 | 表达质量 |
| --- | --- | --- | --- |
| 1.0–3.9 | 价值很小，或主要局限于边缘、局部问题。 | 已确认核心结论存在实质错误或根本性失配。 | 关键内容难以理解，无法形成一致的研究主线。 |
| 4.0–5.9 | 有具体价值，但收益或对核心问题的作用有限。 | 有局部支持，但主要论证或证据仍有重要缺口。 | 大体能理解，但结构、定义或解释存在明显不足。 |
| 6.0–7.9 | 回答重要问题，对相关认识或实践有明确收益。 | 核心材料已检查，主要结论有合理至充分的支持，剩余不足不动摇主要结论。 | 主线基本完整至清楚，主要内容便于理解和查找。 |
| 8.0–8.9 | 对一类重要问题的关键瓶颈有显著价值。 | 核心论证严谨，关键验证和复核信息充分。 | 准确、紧凑，复杂内容有有效解释。 |
| 9.0–10.0 | 对核心认识、能力或重要实践具有深远至决定性价值。 | 在声明与核查范围内支持非常充分，仅有很小或无可识别的实质缺口。 | 接近示范性的清晰、准确、简洁与可核查性。 |

评分应说明相邻锚点的差别；无法合理细分时给一位小数的区间。信息不足或尚未核查时明确写“暂无法判断”或“未核验”，不以低分代替未知。新增三项不使用创新性的 0.0 特殊状态。

可靠性高分要求实际检查核心论证和证据。已确认实质推翻核心结论的问题不能被其他维度的高分抵消；审核者尚未拿到附录，也不能被当作“稿件没有证明”。纯理论稿件不因缺少实验或代码自动扣分，检查要求随贡献类型调整。

**评估方式**

1. 明确研究目标、观测信息、数据获取方式与主要约束，区分设想和已完成成果。
2. 对照最邻近的已有问题、方法或定理，构造使用现成工具的最强合理基线。
3. 判断已有结果能解决什么、具体在哪个核心环节失效，以及新工作增加了什么；新认识型贡献还须比较已有认识，不能只根据工具成熟度降级。
4. 确定贡献类型、创新层级和分数，解释相邻锚点差别及升级所需的实质贡献。
5. 分别报告成果验证状态、新颖性判断置信度与尚待核实的关键点。

方法或算法、理论、建模或框架、统一或综合、新认识或新发现是并列类型。纯理论成果可以得到高分，不要求同时提出算法和匹配的上下界。多项贡献的总体定位由支撑主要结论的核心贡献决定，不平均或累加分数，已在理论或框架贡献中计入的认识不重复计新。

完整审稿在上述创新评估之外，依据现有稿件分别评价重要性、可靠性和表达质量。意见按影响核心结论的问题、主要补充、表达修正排序，尽量说明稿件位置、问题依据、对结论的影响和修复建议。

**独立重复评分**

先冻结稿件版本、创新点、最邻近工作和核验材料，再在相同规则与运行条件下执行五轮隔离上下文评价。每轮分别评价各创新点和整篇工作，整篇分数仍由核心贡献判断。完整四维审核在同一批轮次分别评价四个维度，不计算贡献均分或四维总分。

对新认识贡献，证据包增加“已有认识—新增命题—支持证据—适用边界”，包括未排除的关键解释。每轮核查同一组事实，不预先指定应得分数，也不向评分轮次传入历史成绩。

默认标准差达到 0.4 分或创新层级有分歧时，检查原因并追加五轮，总计十轮；材料或事实修正则另建批次。十轮后仍有分歧就报告，不反复重评到满意为止。用户明确要求单次或其他次数时遵从。没有真实独立执行能力时说明限制，不伪造重复结果。

均值与分数保留一位小数，样本方差保留三位，标准差保留两位，同时报告范围、层级计数及有效次数。未知评分不记零，少于两个有效点分不计算样本方差。均值不自动确定创新层级，也不能抵消可靠性缺陷。

运行方式、OpenAI 官方依据和 JSON 记录格式见 [独立重复评分规范](references/repeated-assessment.md)。使用 Python 3 标准库运行 [统计汇总脚本](scripts/summarize_assessments.py)；它校验记录和计算统计，不发起模型调用。真实评估文件保存在稿件工作目录，便于跨对话复用材料和核对历史批次。

**可选投稿指导**

只有当前请求明确要求选刊、选会、投稿建议或契合度比较时才启动；仅提到目标刊会或只要求创新性评价，不自动分析投稿。

- 限定统计四大时，分别比较 AoS、JASA、Biometrika、JRSS-B。
- 限定机器学习三大时，分别比较 NeurIPS、ICML、ICLR。
- 指定其他目标时按指定列表比较。
- 未限定范围、询问适合投什么时，广泛检索相关出版物，通常先筛选约 10–20 个候选，重点展示 5–8 个。

核对当前官方收稿范围、栏目或分轨、审稿标准及少量近年同类论文，并列出来源与日期。契合度使用独立的 1.0–10.0 分、保留一位小数，附匹配理由、主要差距和当前准备建议。高契合度不等于当前已可投稿，也不是录用概率；材料不足时不强行评分。标准与七个目标的官方检索起点见 [投稿指导规范](references/venue-guidance.md)。

**安装**

将完整仓库放到 Codex 的 `skills/statistical-innovation-assessment` 目录，保留 `SKILL.md`、`references/`、`scripts/` 和 `agents/` 的相对位置。使用默认目录时，该位置为 `~/.codex/skills/statistical-innovation-assessment`；如果设置了 `CODEX_HOME`，则使用该目录下的 `skills/`。

Windows PowerShell 示例，适用于尚未安装此 skill 的环境：

```powershell
$skillInstallRoot = if ($env:CODEX_HOME) {
    Join-Path $env:CODEX_HOME 'skills'
} else {
    Join-Path $env:USERPROFILE '.codex/skills'
}
New-Item -ItemType Directory -Path $skillInstallRoot -Force | Out-Null
git clone https://github.com/zdacongming-glitch/statistical-innovation-assessment.git (Join-Path $skillInstallRoot 'statistical-innovation-assessment')
```

仓库为私有时，克隆需要具有访问权限的 GitHub 登录。已安装此 skill 的环境无需重复克隆。

**使用**

在 Codex 中通过 `$statistical-innovation-assessment` 调用，并附上研究材料。例如：

```text
使用 $statistical-innovation-assessment 评估下面的统计研究设想。
先确定创新层级，再按十分制评分并保留一位小数。
请区分自然技术路线的条件性潜力与更高定位所需的实质发现。
按固定材料进行五轮独立评价，报告实际次数、均值、样本方差和层级分歧；材料不足时不强行打分。

研究目标：……
观测信息、数据获取方式与主要约束：……
拟采用的方法或核心想法：……
已知的最邻近工作：……
目前已有的结果与尚未验证的部分：……
```

审核完整稿件时，可以使用：

```text
使用 $statistical-innovation-assessment 完整审核这份稿件。
请按创新性、重要性、可靠性、表达质量四个维度独立评分，均保留一位小数。
创新性沿用原三级标准；其余三项按各自的十分制锚点评价，不生成加权总分。
请给出评分依据、可靠性核验范围和关键缺陷，并按优先级提出修改建议。
用同一证据包进行五轮独立审核，分别汇总四个维度的均值与样本方差。

成果材料与相关文献：……
本次需要的投稿指导（可选，不填写则不分析）：……
```

需要判断新颖性时，skill 会要求核查最邻近的原始工作；若只需基于现有材料初步定位，可在请求中说明检索范围或要求暂不检索，结论将相应限定。

如果只需要创新定位，在请求中说明“仅评创新性”即可，不会自动扩展为完整稿件审核。只要求其他某一维度时，同样按指定范围评价。

针对新认识贡献，可以使用：

```text
使用 $statistical-innovation-assessment 仅评创新性。
这项工作主要使用已有工具，但声称发现了以下新 insight：……
请核查已有认识与新增命题，在现有三级、十分制量表内按对应判据评分。
不要只因工具已有而归入第三级，也不要因结论重要或令人惊讶就自动升级。
已知文献、成立条件、支持证据与尚未核实的解释：……
```

明确请求投稿指导的例子：

```text
我的目标是统计学四大顶刊，请分别给出当前稿件对四个期刊的契合度、一位小数评分及投稿准备建议。

我的目标是 NeurIPS、ICML、ICLR，请按各会议相关年份的官方标准比较契合度。

这个研究适合投什么？请广泛检索相关期刊和会议，说明主投、冲刺与备选理由。
```

这些请求启动可选投稿模块；“仅评创新性，目标期刊是 AoS”中的目标仅作背景，不自动给契合度或选刊建议。

**输出示意**

以下仅演示表达格式，不对应真实研究的评分：

| 维度 | 跨轮次均值／层级 | 样本方差 | 标准差 | 有效点分 | 主要依据与不足 |
| --- | --- | --- | --- | --- | --- |
| 创新性 | 6.4/10；五轮均为第二级 | 0.013 | 0.11 | 5/5 | 已核查的新构造揭示关键机制；尚未形成更具统摄力的理论认识。 |
| 重要性 | 7.2/10 | 0.020 | 0.14 | 5/5 | 回应领域内核心需求，贡献具有明确价值。 |
| 可靠性 | 5.4/10；五轮均为重要证据缺口 | 0.015 | 0.12 | 5/5 | 新构造的基本有效性有支持，但另一项主要性能优势声称只得到局部验证。 |
| 表达质量 | 7.6/10 | 0.025 | 0.16 | 5/5 | 贡献与论证结构清楚，局部术语与图表解释仍需统一。 |

创新性示例的逐轮分数为 6.2、6.4、6.3、6.5、6.4，范围为 6.2–6.5；其他各维度也应保留实际逐轮记录。核验范围应具体列出已检查的定理、证明、实验材料及未检查部分。此例的优先修改是补足性能比较的关键证据或收窄相应声称，不能通过四项平均分认定稿件已充分可靠。判断置信度及其理由另行说明；方差小也不能排除共同误判。
