# 统计研究创新性与稿件评估

`statistical-innovation-assessment` 是一个用于统计研究创新定位和稿件审核的 Codex skill。它支持“仅评创新性”和“四维完整审稿”两种模式，评分均保留一位小数，并给出可核查的依据。

适用于研究问题、初步选题、方法、定理和完整论文。对于初步设想，评估条件性创新潜力；对于已有成果，评估当前实际贡献。只有摘要或设想时，不强行给整篇稿件的可靠性与表达质量打分。

**四个评价维度**

| 维度 | 核心问题 | 评分方式 |
| --- | --- | --- |
| 创新性 | 带来了什么新东西？ | 原三级分类与十分制完全保留。 |
| 重要性 | 这项工作有多大价值？ | 独立的 1.0–10.0 分，评价理论、科学或实践意义。 |
| 可靠性 | 现有结论是否得到可信支持？ | 独立的 1.0–10.0 分，同时报告核验范围与关键缺陷。 |
| 表达质量 | 是否清楚、准确且便于核查地传达工作？ | 独立的 1.0–10.0 分，评价实际提供的稿件文本。 |

四项分别报告，不求平均或加权总分。假设合理性、实验设计、计算可行性、可复核性等属于内部检查点，不另设评分维度。目标期刊或会议的匹配度放在总体建议中讨论。

**创新性评分：保留原标准**

| 层级 | 分数区间 | 核心含义 |
| --- | --- | --- |
| 第一级 | **8.0–10.0** | 基础概念或研究范式创新：改变一类统计问题的提出方式、目标定义、识别逻辑或证据组织方式。 |
| 第二级 | **4.0–7.9** | 实质性方法、理论或框架创新：解决已有结果未解决的核心障碍，形成可复用的构造、结论或分析原则。 |
| 第三级 | **1.0–3.9** | 迁移、适配或组合应用：应用对象或条件发生变化，核心统计困难仍由现有结果解决。 |

先按贡献性质定级，再在该层级内细分，例如 **第二级，6.4/10**。整数分也保留一位小数，例如 **6.0/10**。评分依据包括最邻近工作的不足、具体核心增量，以及相对相邻评分锚点已经达到和仍然缺少的内容。

两道升级门槛：

- **3.9 → 4.0**：必须超出直接推论或标准适配，解决新的核心障碍。
- **7.9 → 8.0**：必须改变基础概念或问题组织方式，并由此产生具体的新问题或结论。

小数用于层级内细分，不能靠四舍五入跨越门槛，也不代表客观测量精度。证据不足以确定单点分数时，可给出如 **6.0–6.5/10** 的判断区间；跨层级区间须同时标明层级待定。

经核实与已有工作实质重复、没有新增贡献时，单列 **0.0/10**，不归入第三级；材料不足则标为 **暂无法判断**，不赋分。0.1–0.9 不使用。

完整的十个整数锚点、小数细分方法和边界判据见 [完整判据](references/rubric.md)，具体情形见 [边界与评分示例](references/examples.md)。

**新增三个维度的评分标准**

下表是区间概览；三个维度各自的十个整数锚点与小数规则见 [四维稿件审核标准](references/manuscript-review.md)。这些分数不套用创新性的三级分类，也不共用投稿门槛。

| 分数区间 | 重要性 | 可靠性 | 表达质量 |
| --- | --- | --- | --- |
| 1.0–3.9 | 价值很小，或主要局限于边缘、局部问题。 | 已确认核心结论存在实质错误或根本性失配。 | 关键内容难以理解，无法形成一致的研究主线。 |
| 4.0–5.9 | 有具体价值，但收益或对核心问题的作用有限。 | 有局部支持，但主要论证或证据仍有重要缺口。 | 大体能理解，但结构、定义或解释存在明显不足。 |
| 6.0–7.9 | 回答重要问题，对相关认识或实践有明确收益。 | 核心材料已检查，主要结论有合理至充分的支持，剩余不足不动摇主要结论。 | 主线基本完整至清楚，主要内容便于理解和查找。 |
| 8.0–8.9 | 对一类重要问题的关键瓶颈有显著价值。 | 核心论证严谨，关键验证和复核信息充分。 | 准确、紧凑，复杂内容有有效解释。 |
| 9.0–10.0 | 对核心认识、能力或重要实践具有深远至决定性价值。 | 在声明与核查范围内支持非常充分，仅有很小或无可识别的实质缺口。 | 接近示范性的清晰、准确、简洁与可核查性。 |

评分应说明相邻锚点的差别；无法合理细分时给一位小数的区间。信息不足或尚未核查时明确写“暂无法判断”或“未核验”，不以低分代替未知。新增三项不使用创新性的 0.0 特殊状态。

可靠性高分要求实际检查核心论证和证据。已确认实质推翻核心结论的问题不能被其他维度的高分抵消；审核者尚未拿到附录，也不能被当作“稿件没有证明”。纯理论稿件不因缺少实验或代码自动扣分，检查要求随贡献类型调整。

**评估方式**

1. 明确研究目标、观测信息、数据获取方式与主要约束，区分设想和已完成成果。
2. 对照最邻近的已有问题、方法或定理，构造使用现成工具的最强合理基线。
3. 判断已有结果能解决什么、具体在哪个核心环节失效，以及新工作增加了什么。
4. 确定贡献类型、创新层级和分数，解释相邻锚点差别及升级所需的实质贡献。
5. 分别报告成果验证状态、新颖性判断置信度与尚待核实的关键点。

方法或算法、理论、建模或框架、统一或综合创新是并列类型。纯理论成果可以得到高分，不要求同时提出算法和匹配的上下界。多项贡献的总体定位由支撑主要结论的核心贡献决定，不平均或累加分数。

完整审稿在上述创新评估之外，依据现有稿件分别评价重要性、可靠性和表达质量。意见按影响核心结论的问题、主要补充、表达修正排序，尽量说明稿件位置、问题依据、对结论的影响和修复建议。

**安装**

将完整仓库放到 Codex 的 `skills/statistical-innovation-assessment` 目录，保留 `SKILL.md`、`references/` 和 `agents/` 的相对位置。使用默认目录时，该位置为 `~/.codex/skills/statistical-innovation-assessment`；如果设置了 `CODEX_HOME`，则使用该目录下的 `skills/`。

Windows PowerShell 示例，适用于尚未安装此 skill 的环境：

```powershell
$skillInstallRoot = if ($env:CODEX_HOME) {
    Join-Path $env:CODEX_HOME 'skills'
} else {
    Join-Path $env:USERPROFILE '.codex/skills'
}
New-Item -ItemType Directory -Path $skillInstallRoot -Force | Out-Null
git clone https://github.com/zdacongming-glitch/statistical-innovation-assessment.git (Join-Path $skillInstallRoot 'statistical-innovation-assessment')
```

仓库为私有时，克隆需要具有访问权限的 GitHub 登录。已安装此 skill 的环境无需重复克隆。

**使用**

在 Codex 中通过 `$statistical-innovation-assessment` 调用，并附上研究材料。例如：

```text
使用 $statistical-innovation-assessment 评估下面的统计研究设想。
先确定创新层级，再按十分制评分并保留一位小数。
请区分自然技术路线的条件性潜力与更高定位所需的实质发现。

研究目标：……
观测信息、数据获取方式与主要约束：……
拟采用的方法或核心想法：……
已知的最邻近工作：……
目前已有的结果与尚未验证的部分：……
```

审核完整稿件时，可以使用：

```text
使用 $statistical-innovation-assessment 完整审核这份稿件。
请按创新性、重要性、可靠性、表达质量四个维度独立评分，均保留一位小数。
创新性沿用原三级标准；其余三项按各自的十分制锚点评价，不生成加权总分。
请给出评分依据、可靠性核验范围和关键缺陷，并按优先级提出修改建议。

成果材料与相关文献：……
目标期刊或会议（可选）：……
```

需要判断新颖性时，skill 会要求核查最邻近的原始工作；若只需基于现有材料初步定位，可在请求中说明检索范围或要求暂不检索，结论将相应限定。

如果只需要创新定位，在请求中说明“仅评创新性”即可，不会自动扩展为完整稿件审核。只要求其他某一维度时，同样按指定范围评价。

**输出示意**

以下仅演示表达格式，不对应真实研究的评分：

| 维度 | 评分 | 主要依据与不足 |
| --- | --- | --- |
| 创新性 | 第二级，6.4/10 | 已核查的新构造揭示关键机制；尚未形成更具统摄力的理论认识。 |
| 重要性 | 7.2/10 | 回应领域内核心需求，贡献具有明确价值。 |
| 可靠性 | 5.4/10 | 新构造的基本有效性有支持，但另一项主要性能优势声称只得到局部验证，存在重要证据缺口。 |
| 表达质量 | 7.6/10 | 贡献与论证结构清楚，局部术语与图表解释仍需统一。 |

核验范围应具体列出已检查的定理、证明、实验材料及未检查部分。此例的优先修改是补足性能比较的关键证据或收窄相应声称，不能通过四项平均分认定稿件已充分可靠。判断置信度及其理由另行说明。

这是一套自定的研究评价标准，不代表学界统一评级。创新性、重要性、可靠性和表达质量分别评价；成果成熟度、核验范围与判断置信度也单独说明。第三级创新仍可能具有很高的应用或科学价值。评分不替代实际核查，也不换算成期刊录用概率或长期影响力。
